### 1. 다음 코드 실행시 버튼을 눌렀을때때 출력값은?

```javascript
const $button = document.querySelector("button");

const clickFunction1 = () => {
  console.log("[1]button click");
};

const clickFunction2 = () => {
  console.log("[2]button click");
};

$button.addEventListener("click", clickFunction1);
$button.addEventListener("click", clickFunction2);
$button.addEventListener("click", clickFunction1);
```

<details>
  <summary>정답</summary>
  3번째로 등록한 function1은 이미 등록된 리스너라 재등록이 되지않아, 기존의 순서대로 이벤트가 출력된다.

```
[1]button click
[2]button click
```
